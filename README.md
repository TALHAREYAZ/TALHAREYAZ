# 👨‍🔬 About Me

> **AI researcher working toward intelligent, cooperative and communication-aware autonomous systems for challenging underwater environments.**

I am a **Junior Research Fellow at Amrita Vishwa Vidyapeetham, Coimbatore**, working at the intersection of:

🧠 **Artificial Intelligence**  
🤖 **Autonomous Systems**  
🌊 **Underwater Robotics**  
🛰️ **Multi-Agent Intelligence**  
📡 **Software Defined Radio**  
🗺️ **Intelligent Path & Trajectory Planning**

My current work investigates how autonomous underwater vehicles can
**perceive, plan, coordinate and communicate** in complex underwater
environments.
